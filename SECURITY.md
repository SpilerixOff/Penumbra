# Security / Sécurité

Penumbra is in development. There is no established security support period or guaranteed response time. Report issues against the current development branch and identify the affected commit or version.

## Report a vulnerability

If **Security → Report a vulnerability** is available on this repository, use it for a private report. Include the affected version, prerequisites, impact and the smallest reproduction you can provide. Do not include real credentials, other players' data or a private world save.

If private reporting is unavailable, open an issue requesting a private contact method **without exploit details or sensitive data**. Wait for a private channel before sharing those details. Ordinary crashes without a security impact can use the bug-report template.

Relevant concerns include a client affecting another player's private state, unauthorized photo access, unsafe network payload handling, file access outside intended directories and server denial of service. Test only on systems and worlds you control or have permission to assess.

## Français

Penumbra est en développement, sans durée de support ni délai de réponse garantis. Indiquez la version ou le commit concerné.

Si **Security → Report a vulnerability** est disponible, utilisez ce canal privé. Décrivez les conditions, l'impact et une reproduction minimale, sans identifiants réels, données d'autres joueurs ou sauvegarde privée.

Si ce canal est indisponible, ouvrez une issue demandant un moyen de contact privé, **sans détails d'exploitation ni données sensibles**. Attendez ce canal avant de transmettre les détails. Pour un crash ordinaire sans impact de sécurité, utilisez le modèle de rapport de bug.

Les problèmes d'isolation entre joueurs, d'accès aux photos, de messages réseau, d'accès aux fichiers et de déni de service serveur sont notamment concernés. Limitez vos essais aux systèmes et mondes que vous contrôlez ou que vous êtes autorisé à tester.
